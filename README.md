Entry for the [make.fun bounty "The Robot Vacuum's Funniest Excuse"](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2).

`main.py` (pure Python standard library, no third-party packages) writes a
single line — at most 120 characters — in which a robot vacuum explains why
it missed a spot, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to
`/output/entry.txt`). The line:

> My brush roll filed for workers' comp after one look at that pet hair, so I'm on light duty now.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
